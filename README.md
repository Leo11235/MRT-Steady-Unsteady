## Design and simulate hybrid engine rockets

- **Steady-state analysis** for hotfire, fuel-mass convergence, and multi-variable parametric sweeps.
- **Unsteady (transient) simulation** covering the full time-domain of the tank, valve, injector, combustion chamber, nozzle, and ascent trajectory.
- Learn how to use the program with the [User Manual](https://github.com/Leo11235/MRT-Steady-Unsteady/blob/main/docs/user_manual.md) and how it works with the [Developer Manual](https://github.com/Leo11235/MRT-Steady-Unsteady/blob/main/docs/developer_manual.md).
